# Webtoon Image Merger & Slicer (Batch Processor)

Вэбтүүний олон жижиг хэсэг зургуудыг босоо тэнхлэгийн дагуу автоматаар нэгтгэж, хүссэн өндөр эсвэл тоогоор буцаан хувааж хадгалах Python GUI програм.

## Онцлогууд
- **Багц бүлэг унших (Batch Processing)**: Нэг үндсэн хавтас сонгоход доторх бүх бүлгийг (Chapters) автоматаар таньж боловсруулна.
- **Ухаалаг эрэмбэлэлт (Natural Sorting)**: `1.jpg`, `2.jpg`, `10.jpg` гэх мэт тоонуудыг зөв дарааллаар эрэмбэлнэ.
- **Өргөн тохируулах (Auto Scaling)**: Зургуудын өргөн зөрсөн тохиолдолд харьцааг алдагдуулахгүйгээр масштаблана.
- **Хуваах горимууд**:
  - Өндрөөр хэрчих (Height based split, жишээ нь 1500px, 2000px тутамд)
  - Тэнцүү хэсэгт хуваах (Count based split)
- **Формат & Чанар**: JPEG, PNG, WEBP формат сонголттой ба чанарын тохируулгатай.
- **Орчин үеийн Dark GUI**: Хэрэглэхэд хялбар цэвэр интерфэйс ба явц харуулах прогресс бар.

## Суулгах & Ажиллуулах

```bash
pip install -r requirements.txt
python main.py
```
